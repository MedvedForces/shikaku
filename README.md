# Шикаку на шестиугольной сетке

Небольшая консольная программа для генерации и решения головоломки в духе
Shikaku. Поле состоит из шестиугольных клеток, а числа задают размеры областей:
каждая область должна содержать указанное число клеток, быть связной и не
пересекаться с другими областями.

Программа случайно генерирует поле с подсказками, а затем ищет решения и
показывает разбиение поля на области. Это решатель головоломки, а не
интерактивный редактор для ввода собственных задач.

## Требования

- Python 3.8 или новее
- Сторонние библиотеки не нужны

## Запуск

Из корневой папки проекта выполните:

```bash
python -m shikaku_game
```

На Windows можно использовать `py -m shikaku_game`.

Программа запросит:

1. **Радиус поля** — целое число не меньше 1. Количество клеток на поле равно
   `3 × радиус × (радиус − 1) + 1`.
2. **Количество решений** — максимальное число решений, которое нужно найти;
   значение `0` снимает ограничение.

Сначала будет показано поле с подсказками, затем — найденные разбиения. Если
решений нет, программа сообщит об этом.

## Тесты

Из корневой папки проекта:

```bash
python -m unittest discover -s tests -v
```
